## O QUE ESTÁ BEM DESENHADO (não alterar)
======================================================

- SupplierProvider interface + strategy pattern:
  Adicionar supplier = 1 ficheiro (provider) + 1 linha em providers/index.ts
  + inserção no Supabase (supplier + credencial).

- Template de onboarding de novo supplier (aprendido com Ryme e Air Fren):
  1. Script diagnóstico para descobrir selectores reais do formulário e URL de pesquisa
  2. Provider com dismissCookies/dismissPrivacyBanner antes do login
  3. isLoggedIn() robusto (URL + ausência de form + indicador de conta)
  4. Pesquisa por URL directa (mais fiável que interacção com SPA)
  5. Selectores de parser validados contra HTML real capturado

- withTimeout() wrapping de todas as chamadas a providers:
  Previne que um browser Playwright pendurado bloqueie o request.

- Cache de resultados keyed em supplier.id:query com TTL.

- Isolamento de erros em runSupplierSearch():
  Erros tornam-se SupplierRunResult com status:'error', nunca propagam.

- Sanitização de snapshots debug antes de upload para Supabase Storage.

- buildResponseSummary() e sortAggregatedItems(): funções puras, sem side effects.

- loadEnabledSupplierTargets() com cache de 60s.

- getSupplierKey() centralizado: identificação de suppliers robusta,
  independente do nome no Supabase, lê da BD com fallback por nome.

- search-run-repository.ts: persistência Supabase isolada do scraping.

- parser.ts: todos os parsers HTML (incluindo Nipocar, Ryme, AirFren) num único módulo.

- schedulerRunning flag: impede ticks sobrepostos no setInterval do scheduler,
  garantindo que refreshes de sessão correm sequencialmente.

- GSMART fast-exit: GsmartProvider lança CAPTCHA_REQUIRED imediatamente
  quando não há sessão em cache nem credenciais, sem abrir browser.

- handleCancelSearch(): fecha SSE stream (EventSource.close()) sem afectar sessões
  Playwright em curso no backend; utilizador pode pesquisar nova referência de imediato.

- openProgressStream() em api.ts: SSE com EventSource, push a 500ms.
  Sem polling desnecessário; resultados aparecem assim que cada supplier termina.

- isAuthenticatedEvoPartsHtml() centralizado em evoparts.ts:
  Verificação completa (resultados + pricing signals + client token) exportada para scraper.ts.
  hasAuthenticatedPricingSignals() mantido privado para uso interno do EvoPartsProvider.
