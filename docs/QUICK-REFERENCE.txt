┌────────────────────────────────────────────────────────────────────────────┐
│ 🚀 QUICK START (First Time)                                                │
└────────────────────────────────────────────────────────────────────────────┘

  1. Open CMD (not Git Bash) in ProductScout folder
  2. Run: safe-start-backend.bat
  3. Wait for "Backend is listening on port 3001"
  4. Test: curl http://localhost:3001/health
  5. Done! Backend is running ✅

│ 🔥 EMERGENCY PROCEDURES                                                     │
└────────────────────────────────────────────────────────────────────────────┘

  PROBLEM              SOLUTION
  ───────────────────────────────────────────────────────────────────────
  Exit Code 2          → emergency-stop.bat → safe-start-backend.bat

  Backend Looping      → emergency-stop.bat → safe-start-backend.bat
  Port Won't Free      → emergency-stop.bat (check output)
  Don't Know What      → diagnose-backend.bat → TROUBLESHOOTING.md

  # Check if port 3001 is in use
  netstat -ano | findstr ":3001"

  # List node.exe processes
  tasklist | findstr "node.exe"

  # Test backend manually
  curl http://localhost:3001/health

  # Check npm/node versions
  npm --version
  node --version

  # View latest log
  type logs\backend-start-*.log

┌────────────────────────────────────────────────────────────────────────────┐

  DO:
  ✅ Read error messages before closing windows
